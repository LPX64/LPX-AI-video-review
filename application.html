1. Dodaj nagrania

MP4 i MOV, również w podfolderach. Nagrania pozostają na Twoim komputerze. Oryginały nie są zmieniane.

Ustawienia propozycji

Dotyczy nowej analizy. Cały krótszy film może pozostać krótszy niż minimum.

Bez zaznaczonych kategorii: wszystkie sceny. Kilka kategorii: wystarczy dopasowanie do jednej. Rozpoznawanie może się mylić.

3. Wybierz klipy

Długość propozycji dopasowuje się do obrazu. Punktacja opisuje cechy techniczne nagrania — Ty decydujesz, które momenty warto zachować.

Chronologia nagrań — sprawdź daty i zegary kamer

Daty z metadanych mogą oznaczać zapis pliku, a zegary kamer mogą się różnić. W razie potrzeby wpisz czas początku nagrania ze strefą, np. 2025-11-08T18:40:35+01:00. Nie używamy daty modyfikacji pliku.

4. Podgląd i eksport do DaVinci

Najpierw zaakceptuj klipy. Eksport obejmuje wyłącznie wybrane propozycje.

Pobierz XML

W Resolve: File → Import → Timeline. Nowe XML wskazują oryginalne filmy w folderze źródłowym. Zachowaj ich nazwy i położenie; pliki podglądu nie są potrzebne w Resolve.

Porządki po montażu

Usuń propozycje, podglądy i eksporty wybranego projektu. Oryginały zostają.

Usunąć pliki tego projektu?

Usuniemy wszystkie propozycje, decyzje, miniatury, podglądy, XML i wygenerowane kopie klipów tego projektu. Tej operacji nie można cofnąć.

Zapisz XML poza aplikacją lub zaimportuj go do Resolve przed czyszczeniem. Nowe eksporty wskazują oryginały. Starsze eksporty wersji 1.0 nadal potrzebują folderu media — zachowaj go, jeśli korzystasz ze starej osi czasu.

Oryginalne nagrania pozostaną bez zmian.
